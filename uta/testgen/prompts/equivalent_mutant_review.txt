Worked example of an acceptable `equivalent` argument (Python, `or` -> `and`):

    def text_similarity(left: str, right: str) -> float:
        a, b = normalize_text(left), normalize_text(right)
        if not a or not b:          # mutant: `not a and not b`
            return 0.0
        sequence = SequenceMatcher(None, a, b).ratio()
        grams_a = {a[i:i + 2] for i in range(max(1, len(a) - 1))}
        grams_b = {b[i:i + 2] for i in range(max(1, len(b) - 1))}
        jaccard = len(grams_a & grams_b) / len(grams_a | grams_b) if grams_a | grams_b else 0.0
        return max(sequence, jaccard)

- divergence_region: the predicates differ only when exactly one of `a`, `b` is empty. When both are empty or both are non-empty, they agree.
- why_indistinguishable: with `a == ""` and `b` non-empty, `SequenceMatcher.ratio()` is `2*0/len(b) = 0.0`. `grams_a == {""}`, and every element of `grams_b` is non-empty, so the intersection is empty while the union is not: jaccard is 0.0 and the function returns 0.0. The swapped case is symmetric. No exception or side effect differs.
